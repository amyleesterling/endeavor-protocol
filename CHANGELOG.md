# Changelog

All notable changes to Endeavor Protocol are recorded here.

## [0.1.0-alpha.1] - 2026-08-12

### Added

- Portable `endeavor-protocol` Agent Skill with progressive reference files
- Universal bootstrap instructions for fresh agent instances
- Discovery, Delivery, Audit, Communications, Operations, and Synthesis profiles
- Solo, Delegated, Orchestrated, and Auto capability modes
- Orchestrator, Investigator, Builder, Critic, Verifier, and Synthesizer roles
- Evidence classification, closure states, contradiction handling, and human approval gates
- Persistent `.endeavor/` project state templates
- Safe Python bootstrap script with dry-run and overwrite protection
- Structural validator and automated tests
- EyeWire communications and Discovery Engine examples
- Public contribution and security guidance

### Known limitations

- No hosted orchestration runtime or dashboard
- No built-in model or vendor integration
- No proof yet from broad independent field use
- No guarantee that an agent will follow the protocol correctly
- Not an assurance framework for safety-critical decisions
