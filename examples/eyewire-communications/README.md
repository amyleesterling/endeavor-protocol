# Example: EyeWire Scientific Communications Endeavor

This is an illustrative example. It contains no unpublished EyeWire information.

## Endeavor Brief

**Outcome:** Produce a public-facing release package that is scientifically accurate, understandable to educated non-specialists, useful to neuroscientists, and approved for publication.

**Profiles:** Communications + Audit + Delivery

**Capability mode:** Delegated when separate agents are available; Solo otherwise.

**Required closure:**

- factual claims: E1 sourced and E2 inspected;
- numerical comparisons: E2 reproduced;
- links, names, dates, credits, and permissions: C2 checked;
- final web or publication artifact: C3 target-validated;
- publication: human approval required.

## Suggested roles

### Orchestrator

Owns scope, source-of-truth list, deliverable inventory, approval boundaries, and integration.

### Source auditor

Maps each scientific and numerical claim to the paper, dataset, repository, or approved internal source.

### Audience strategist

Defines what the general public, educators, citizen scientists, and neuroscientists each need to understand.

### Narrative builder

Creates the story architecture and artifacts without changing scientific meaning.

### Critic

Looks for hype, missing caveats, inaccessible language, unsupported novelty, incorrect comparisons, and audience confusion.

### Verifier

Checks every material claim and the final published rendering.

## Work packages

```text
WP-001 Source ledger
WP-002 Audience and channel requirements
WP-003 Narrative and message hierarchy
WP-004 Draft artifact production
WP-005 Scientific and accessibility audit
WP-006 Link, credit, permission, and rendering verification
WP-007 Human approval and publication
```

## Example claim ledger

| Claim ID | Claim | Evidence | Status | Next validation |
|---|---|---|---|---|
| CL-001 | Dataset contains X reconstructed units | primary dataset documentation | sourced | reproduce count or confirm approved statistic |
| CL-002 | The release is larger than an earlier release by factor Y | source values and shown calculation | partially supported | independent arithmetic check |
| CL-003 | The result enables a named scientific use | paper and investigator-approved interpretation | supported | check wording against publication |

## Closure warning

A polished press release is C1 implemented. It is not C2 checked until claims, credits, links, permissions, and rendering have been inspected. It is not approved for publication until the human decision owner approves it.
