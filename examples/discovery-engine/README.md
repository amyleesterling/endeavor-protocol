# Example: Discovery Engine Endeavor

This example shows how Endeavor Protocol can support an open-ended research program without pretending that agent consensus is discovery.

## Endeavor Brief

**Question:** Can a proposed measure reveal hidden or previously unmeasured layers of organization across spatial and temporal scales?

**Profiles:** Discovery + Audit + Synthesis

**Capability mode:** Delegated for literature, formal analysis, toy systems, and hostile review; Solo for the deepest tightly coupled theoretical synthesis.

**Outcome:** A bounded evidence map, competing formulations, decisive toy-system tests, and a recommendation about which idea deserves further development.

## Suggested workstreams

### Prior-art investigator

Searches adjacent fields and terminology. Returns the closest existing measures, differences, and novelty risks.

### Formal analyst

Defines variables, invariances, units, limiting cases, and candidate mathematical relationships.

### Toy-system experimentalist

Constructs controlled systems that isolate persistence, directed causal influence, synergy, recursion, energy normalization, and environmental inheritance.

### Domain translator

Tests whether the primitives can be operationalized in neuroscience, complex systems, or another target domain.

### Hostile reviewer

Attempts to show that the proposal is redundant, ill-defined, unfalsifiable, or merely correlated with system size or computation.

### Verifier

Reproduces calculations and reruns toy tests from the underlying code or data.

### Synthesizer

Identifies what survives, what remains ambiguous, and the next experiment with highest information gain.

## Independence design

Several agents repeating the same summary are not independent.

Better structure:

1. give separate investigators the same question but different source domains;
2. ask at least one analyst to work without seeing the favored formulation;
3. freeze candidate equations before hostile review;
4. make the verifier rerun calculations from inputs;
5. preserve minority interpretations in the contradiction map.

## Closure

This endeavor does not close with “the theory is true.”

Possible defensible closure states include:

- prior-art landscape complete enough for the current scope;
- variables operationalized in toy systems;
- one candidate formulation survives stated invariance and limiting-case tests;
- decisive empirical test identified;
- proposal rejected or deferred with reasons;
- unresolved contradiction preserved.

## Handoff

The handoff should name the strongest surviving idea, the strongest objection, the experiment that would distinguish alternatives, and the exact evidence still missing.
